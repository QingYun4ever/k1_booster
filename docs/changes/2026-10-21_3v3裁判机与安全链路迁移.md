# 变更报告：QYBot 3v3 裁判机与安全链路迁移

- 日期：2026-10-21
- 类型：协议迁移、行为修复、并发状态重构、部署工具修复。
- 位置：只修改 `QYBot`；两份源工程和另一个 agent 的 `Booster/doc` 不动。
- 基线：复制 `k1_booster` 的源码、模型、标定、部署与既有文档，不复制 `.git/build/install/log/node_modules` 等生成目录。
- 默认生效：v12/v20 协议、3v3 名单、角色和所有权、球源隔离、动作 gate、取消与到位滞回。预测接管追球、阵型框架、大力踢仍按原先默认关闭。
- 回退：停止 QYBot，三台整套切回源工程；不要单独替换旧消息或队友通讯库。

## 1. 协议与状态

| 证据 / 原问题 | 修改 / 位置 | 消费者影响 |
|---|---|---|
| v20 将比赛阶段和定位球压缩到旧 `secondary_state` 会丢失加时角球 | `game_controller_packet.h` 保留原始 `gamePhase/setPlay/stopped`；brain `match_policy.h` 分开解释 | 加时不再覆盖定位球类型 |
| 旧报文槽位容量被当作参赛人数 | parser 生成 `RobotInfo.available`；brain 使用配置人数与 `players_per_team` 的较小值 | 未使用槽位不参与存活统计/角色/主攻 |
| 接收超长 UDP 可被截断成合法结构 | 精确字节解码、额外一字节接收缓冲 | 错误长度、未知版本、非法人数/队号/守门员拒收 |
| 接收线程阻塞导致析构等待 | game_controller 100ms poll；队友 socket 200ms 超时；先停线程再关闭 | 无流量时正常退出；不靠 SIGKILL |
| v20 时间允许负数，旧 ROS 字段 unsigned | `GameControlData.msg` 时间直接改为 int16；所有本工程消费者切换 | 必须重新生成消息并整套重编 |
| 无关队伍包先修改 brain 状态 | callback 验证队伍、名单和状态后整体提交 | 非本队包不刷新授权或裁判新鲜度 |
| 旧 PLAY 包可能倒退覆盖新 StopPlay | 有效连接内使用 8bit 包号环绕顺序；过期后允许重新同步 | 重复/旧包不回退状态 |

接收协议：HL v12 688 字节；此次官方本地 v20 158 字节（20 个三字节球员槽位）。不是任意 SPL/其他年度 v20 变体。
返回协议：v12 alive 原格式；v20 返回 v4 32 字节，位姿/球坐标毫米、球龄秒、角度弧度。球龄只来自本机观测，不用队友球伪装。

## 2. 3v3 与球源

- 守门员身份：有效 GC 编号优先，否则全队配置 `game.goalkeeper_id`；被罚下时最小有效 ID 接任。只有一人时，正常比赛进攻、对方定位球等待时守门。没有官方四前锋半场分组。
- 主攻：两个场上球员全场竞争；成本量化产生全序，单一已有 owner 用成本差保持，正在执行视觉技能保留所有权；冲突声明以 ID 解决。
- 断网/关闭通信：GC 名单与 ID 定义保守主攻，不让每台按自己的局部成本分别自选。实际断网/不对称网络仍需三机验证，协议不是分布式一致性保证。
- 删除旧 `tmCmd/cmdId` 主攻与主动守门员交接、角色回退代码；没有旧队友包兼容 shim。
- 队友包切为 `QYTM` v1、64 字节显式大端编码；避免 C++ bool/结构 padding ABI。观测年龄与观测序号独立于通信包号，置信度保持 0–100。
- 网络线程不读写活的 BrainData/行为树：接收固定容量队列；主线程每 tick 更新出站/裁判快照。快照过期时清除存活、主攻和技能声明；观测过期不续命。
- 队友进程重启在地址/状态超时后重置序号；同一观测 ID 的心跳不重写坐标、不刷新源时间。
- 共享库 `ingest(report, now_sec)` 对当前接收端时间验证；拒绝 NaN/未来/旧/重复报告，需要本机定位。`FusedBall.source_stamp_sec` 在保持期不变；融合不会延长有效期。
- `data->ball` 保持本机真球/记忆，`tmBall` 独立；共享球仅供 `getBallForChase()` 搜索/接近。射门必须有本机新鲜视觉、定位、主攻权、合法 PLAY，且非等待对方开球。

## 3. 动作、定位与部署

- `Brain::isMotionAllowed/isKickAllowed/hasFreshLocalBall` 收敛授权；StopPlay、SET、判罚、比赛结束、过期裁判禁止新身体运动/技能。离线手动/chase 调试仅在从未收到裁判且不处于自主 game 模式时允许。
- 起身使用同一裁判授权但独立的 `isRecoveryAllowed`，摔倒/起身中不允许 Chase 行走；拒绝的起身请求不会被标记为已经执行。
- 所有 ROS callbacks/tick 改为单线程执行器；不再让独立 callback 线程和 tick 同时修改行为树。100Hz wall timer 执行 tick。
- `RobotClient::stopMotion()` 幂等零速度并取消已启动 VisualKick/RL/fancy，不在暂停时自动蹲起。通用 RPC `call` 变 private。
- 停止/失去球源/失去主攻立即取消；正常技能退出直到取消请求发出后才释放 `tmImInVisualKick`。RPC 成功表示请求已发布，不等同固件动作完成确认。
- 本机新鲜球才启动视觉技能；不同观测帧且距离实际减小才算进展，2s 无进展退出；保持旧版 1000ms 减速，不照抄官方 80ms。
- READY、守门员站位复用 `ArrivalLock` 滞回；点球守门目标门线前 0.05m，并限制释放距离。实际脚部接触门线的规则仍需按机器人足形/定位误差现场确认。
- 保留旧版定位表达式/循环/过滤、双向头限位、弧线 Chase、主动找球；未启用休眠 PT/中圈校正器。重定位重置预测/共享历史，并同步重新投影地标、球门柱。
- 观测输入检查有限值、时间、数组长度；旧 recovery `memcpy(buffer.size())` 越界路径改为精确三字节解码。
- XML 修复原 `chase.xml` 属性中的裸 `<`；新的 StopPlay/点球分支均使用合法转义。启动不再用 XML RunOnce 重置控制状态，LT+X 取消不会因 halt 自动变回自主。
- kickoff guard 只计算不同真实观测，定位跳变重锁；不会仅因十秒到期自动认为已经触球。小速度第一脚在整个 Kick 运行中保持，而不只约束开始帧。
- 补全既有 `kick_range/kick_theta_range/soft_kickoff/abort_kick_ball_move_threshold/always_turn_left` 等参数声明，避免旧代码读不到参数。
- `start.sh` 不再屏蔽系统更新或全局杀 Python；标定目录可配置。TERM 停止等待五秒，未退出拒绝重启，保护技能取消和 UDP 端口独占。
