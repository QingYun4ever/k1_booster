# 变更报告：动态接应与中路保护

- 日期：2026-10-23。
- 默认生效：普通 PLAY 中非主攻前锋的 `Assist` 节点。
- 不新增踢球/传球协议，不改变裁判门控；缺少球源或主攻位姿时停止，不盲走固定位置。

## 改动

`src/brain/include/tactical_support.h` 使用最多九个固定候选，比较球后保护位、左右斜侧接应与条件式前场二点位。先裁剪场界，再检查双方禁区、距球至少1.2m、距主攻至少1m、射门/主攻接近通道和障碍路径。没有合法候选返回无效计划。

己方半场优先保护球到本方球门通道；仅在进攻半场、主攻已近距离控球且没有近距离对手压迫时允许前侧二点位。位置围绕球更新，不再由五人制成本 rank 固定分层。

`Assist::tick` 接入真实 planner，面向球移动；线速度按同一缩放系数限幅，保持 planner 检查过的路径方向，避免独立夹紧 x/y 后穿过障碍。复用到位/离位滞回。owner 变更时重置接应计划。

接应保持锁定原始参考球/主攻位置，小变化不来回换位；累计超过0.4m或原计划不合法就重算，不能每帧刷新参考让旧目标无限保留。

遥测增加 `support_valid/support_role/support_target`。没有运行 Assist 的帧显示 hold，不遗留旧有效状态。移除未使用的 Assist `dist_to_goalline` 端口。

## 已执行验证

`python tools/check_native.py`：既有六组和新增支持回归均通过，覆盖镜像、球门/边线、主攻通道、障碍绕行、无效输入、参考保持与累计球移动。

临时原生 smoke 的真实 `chooseSupport` 输出：己方场景选择(-2.1,0) cover；球移动0.15m保持原合法位置；进攻控球场景选择(2.85,2.0) rebound。临时文件已删除。

## 风险和赛场验证

规划使用当前可见障碍和队友位姿，不保证未观测空间无敌人。旧障碍时效和0.6m场界余量沿用保守估计。需要真机验证相机失球不自走、owner变更及时让位、左右换位不穿主攻路径、己方危险区域保持中路，以及实际动作路径与计算直线一致。本机没有 ROS2/Jetson/机器人运行环境。
