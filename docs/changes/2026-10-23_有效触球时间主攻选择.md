# 变更报告：按有效触球时间选择主攻

- 日期：2026-10-23。
- 类型：默认生效的 3v3 角色成本优化；不放宽裁判、定位或真球门控。

## 改动

`src/brain/include/tactical_timing.h` 将“距离＋角度混合值”改为秒：比较侧移与转身行走时间、球后 0.35m 触球姿态、绕球时间、观测时效和可信度。存在有效预测速度时可在六秒窗口内估计拦截；超出窗口返回不可达，不把截断值当作可达时间。

`Brain::handleCooperation` 为所有候选使用同一个可用球源、同一球门中心方向、同一行走限速重新计算成本，而不是混合不同机器人的历史自报 cost。候选球源按可信度、player ID 决定；旧 owner 保持与技能所有权规则仍生效。协议没有扩展球速度或对手地图，因此全队 owner 选择使用静态球模型、忽略局部障碍清单，避免某台看到障碍就独自改变全队排序。没有共同观测时仍用各机有限本机记忆并保守降级，不能宣称分布式一致性保证。

`Brain::getTacticalWorld` 收集有限容量的真实球/队友/对手证据，供后续接应与出球规划复用；本机球对象不被队友球覆盖。遥测增加 `touch_costs_seconds`。

## 已执行验证

`python tools/check_native.py` 成功运行既有五组及新增时序回归；测试覆盖球后姿态、方向、横移、越界触球、异常输入、球源平局与旧观测、滚动球可达窗口。

临时原生 smoke 使用真实 estimator 和 owner，编译/运行退出码 0：

| 场景 | 1号成本 | 2号成本 | 主攻 |
|---|---:|---:|---:|
| 1号近但在球侧，2号已在球后 | 3.250s | 1.194s | 2 |
| 1号移动到球后且方向正确 | 0.528s | 1.194s | 1 |
| 1号朝向反向 | 3.669s | 1.194s | 2 |

滚动球原生回归中，落后于更快球的球员不可达，位于球前的候选估计 0.8s 接触。临时 smoke 文件已经删除。

## 风险与上机检查

这些数值是基于配置行走速度的估计，不是机器人实测到球时间。现有预测默认关闭，全队 owner 没有共享速度，本次未开启预测。必须在真实 ROS2/Jetson 环境构建，测不同方向/距离到球时延与 owner切换；确保不增加换人来回走动、争球和主攻空缺。机器人实机运动仍未在本机验证。
